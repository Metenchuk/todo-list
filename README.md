# Todo List

Простий додаток для керування завданнями на Next.js 14+, TypeScript та Tailwind CSS.

## Запуск

```bash
npm install
npm run dev
```

## Функції

- Додавання, видалення та відмітка завдань
- Фільтрація завдань (всі / активні / виконані)
- Збереження в localStorage
- Лічильник невиконаних завдань
- Стан завантаження при ініціалізації

## Покращення

- Редагування завдання по подвійному кліку
- Drag & drop
- Анімації
